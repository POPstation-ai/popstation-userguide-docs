    モード編集

    モードについて

    「モード」とは、だれでも簡単にAIを使えるようにするための「AIへの依頼内容と入力項目をひとまとめにしたテンプレート」です。
    モードを作成しておけば、次回からはフォームに必要な情報を入力するだけでOK！
    毎回同じ指示を入力することなくAIを利用できます。
     プロンプトを考えたり入力したりする手間を減らし、誰でも同じ品質でAIを活用できます。
    * あなただけの専用モードを作れば、AIを有能なアシスタントとして使うことができます。

    🎯 例えばこんな時に使えます（活用シーンの例）

    「モード編集」を使って専用の入力フォームを社内共有すると、繰り返し使うときだけでなく、AIを使い慣れていないメンバーでも、ボタン一つで定型業務を終わらせることができるようになります。

    1. メールの文面作成（定型文の量産）
    「送信相手」「要件」「トーン」を選ぶだけで、一瞬でビジネスメールが完成します。
    プロンプトの裏側： {{相手}}宛てに、{{要件}}を伝えるメールを{{トーン}}な文章で作成してください。
    フォームに設置するパーツ： テキスト（相手・要件）、ドロップダウン（トーン：丁寧／カジュアル）

    2. 外国語への翻訳・ローカライズ
    「翻訳したい文章」を入力し、「ターゲット言語」を選ぶだけで、社内の誰もが同じ精度で翻訳できるようになります。
    プロンプトの裏側： 以下のテキストを{{言語}}に翻訳してください。専門用語はそのまま残してください。：{{文章}}
    フォームに設置するパーツ： 複数行のテキスト（文章）、ドロップダウン（言語：英語／中国語／韓国語）

    3. 記事やSNS投稿のキャッチコピー生成
    「商品名」と「ターゲット層」を入力し、追加で「アピールしたい強み」を入力させて、魅力的なキャッチコピーを複数提案させるフォームです。
    プロンプトの裏側： {{商品名}}を{{ターゲット}}に向けて訴求するキャッチコピーを5案考えてください。追加条件：{{追加のこだわり}}
    フォームに設置するパーツ： テキスト（商品名）、ドロップダウン（ターゲット：20代女性／ビジネスマン）、オプションテキスト（追加のこだわり ※任意入力）

    モード編集画面から、モードの追加・編集・削除ができます。
    モード編集画面の入力に合わせて、テキストボックスやプルダウンなどが設定された入力フォームが自動で生成されます。生成されたフォームは「モード」として使うことができ、使う人がそのフォームに入力して送信すると、プロンプト欄の内容と合体してAIに送信されます。

    モード編集画面への遷移

    1. メイン画面左下の「メニュー」「モード管理」の順にクリックしてください。

    2. モード一覧画面が表示されます。

      表示項目

      モード一覧画面では各モードごとに以下の項目が表示されています。

      • モード名：モードの名前
      • 説明：モード説明
      • カテゴリ：モードが分類されているカテゴリ
      • モデル：デフォルトで設定されているAIモデル
      • 設定：モードの設定
      • 利用回数：これまでにモードが利用された合計回数

    モードの追加

    1. 画面右上のモード追加ボタンをクリックしてください。

    2. 入力フォームに必要事項を入力してください。

      入力事項の説明

      入力する内容は以下の項目です。(太字は必須事項です。)

      1. タイトル
        • モードの名称です。
      2. 説明
        • モードの機能や特徴の説明です。モード選択画面に表示されます。
      3. 利用ガイド
        • モードの使い方の詳細な説明です。モード実行画面に表示されます。
      4. プロンプト
        • モードを実行するときにAIが回答の生成を行う際のプロンプトのテンプレートを、「穴埋め式の指示書」形式で作成することができます。
        • テキストボックスなどの条件入力の記述方法につきましては、本ページ内の「モードプロンプトの書き方」の項をご確認ください。
      5. データ参照先
        • AIに「どの資料（データ）をベースにして回答させるか」を指定します。「カスタムデータ」「カスタムデータ:ナビゲーションチャット」「Web検索」「URL読込」から選択できます。
        • 「カスタムデータ」を選択すると、参照するデータフォルダを選択するメニューが表示されます。複数のデータフォルダを同時に選択して参照することができます。
        • 「カスタムデータ:ナビゲーションチャット」を選択すると、曖昧な質問に対してAIが関連するカスタムデータを提示しながら対話を進める機能が有効になります。複数のデータフォルダを同時に選択して参照することができます。
        • 「Web検索」を選択すると、プロンプトから関連するWebページを参照して回答します。
        • 「URL読込」を選択すると、入力したURLを参照して回答します。
      6. 用途
        • モードの分類を行う機能です。
        • 設定を行わない場合、自動的に未分類カテゴリに分類されます。
      7. AIモデル
        • 利用する生成AIのモデルを設定できる機能です。
        • 設定を行わない場合、システムのデフォルトモデルが使用されます。
        • システムのデフォルトモデルについては「システム管理」の説明ページを確認してください。
      8. オリジナルプロンプトの表示
        • モードが実行された際に、プロンプト全文を表示するかの有無を設定できる機能です。
      9. 共有範囲
        • モードを公開する範囲を設定します。以下の4つの範囲から選択できます。
          • 組織全体: 同じ組織（テナント）内の全ユーザーが利用できます。
          • 指定のユーザーグループ: 選択したユーザーグループに所属するメンバーのみ利用できます。
          • 指定のユーザー: 個別に指定したユーザーのみ利用できます。
          • モード作成者のみ: 作成者本人のみが利用できます。（個人モード）
        • ※管理者およびユーザー管理者は、他のユーザーが作成したモードの共有範囲を変更することができます。
      10. 公開設定
        • モードを「公開」にするか「非公開」にするかを切り替えます。
        • 非公開に設定すると、共有範囲内であってもモード選択画面には表示されず、利用できなくなります。
      11. 利用可能なモデル
        • このモードで使用できるモデルを設定する機能です。
        • チェックを入れたモデルのみが、モード実行時の選択肢として表示されます。
        • ※利用者自身が使用権限を持たないモデルは、ここでチェックを入れても表示されません。

    3. 入力完了後に、追加ボタンをクリックするとモードが追加されます。

      注意点

      ※ モードプロンプトのフォーマットが正しくない場合は保存できません。

    モードの編集

    モード作成者と管理者・ユーザー管理者は、モードの編集を行うことができます。

    1. モード管理画面から、修正するモードの右端にある「…」をクリックして、変更ボタンをクリックしてください。

    2. 変更箇所を編集してください。

    3. 保存ボタンをクリックすると変更が保存されます。

    モードの複製

    既存のモードの設定をコピーして新しいモードを作成することができます。

    1. モード管理画面から、複製したいモードの右端にある「…」をクリックして、複製ボタンをクリックしてください。

    2. 元のモードの設定（タイトル、説明、プロンプト等）が入力された状態で編集画面が表示されます。必要に応じて内容を調整し、保存ボタンをクリックしてください。

    モードの削除

    モード作成者と管理者・ユーザー管理者は、モードの削除を行うことができます。

    修正するモードの右端にある「…」をクリックして、削除ボタンをクリックしてください。

    モードプロンプトの書き方

    モードのプロンプトでは、POPstation特有の書き方があります。

    プロンプト欄は、実行時のベースとなる「定型プロンプト文」と、動的に内容を差し替える「入力フォーム用のパーツ」で構成されます。
    各パーツは { } で囲む形で記述します。この { } 内には、「入力フォームを自動生成するための『設定項目（パラメーター）』」を定義します。
    ユーザーが画面上のフォームで入力・選択した内容は、実行時にこの { } の部分へ自動的に組み込まれ、定型プロンプト文と合体してAIへ送信される仕組みです。

    各パーツを設置するときの書き方のイメージ

    共通項目（title, description, optional）と、パーツのタイプ（text, multi-line-text, select）を { } の中で組み合わせてプロンプト欄に入力します。

    • 入力が必須のテキストボックス：

      #{title: "文章", description: "入力必須です", type: "text"}

    • 空欄でも送信できる（任意設定の）テキストボックス：

      #{title: "追加のこだわり条件", description: "あれば入力してください", optional: "true", type: "text"}

    モードに埋め込めるパーツ

    プロンプト欄に埋め込めるパーツには以下のような種類がありますので、状況に応じてご使用ください。

    • テキストボックス テキストボックスを埋め込むことができます。プロンプトに改行のないテキストをユーザー入力欄として埋め込みたいときに使用してください。

      モードプロンプトに貼り付けるコード：テキストボックス
      #{title: "テキストボックス", type:"text"}

    • 複数行のテキストボックス 改行可能なテキストボックスを埋め込むことができます。プロンプトに改行を含むテキストをユーザー入力欄として埋め込みたいときに使用してください

      モードプロンプトに貼り付けるコード：複数行のテキストボックス
      #{title: "複数行のテキストボックス", type:"multi-line-text"}

    プロンプト内に「改行」は入れるべき？

    プロンプトには、適度に改行や空行を入れることをおすすめします。
    改行を入れる場合：
    AIが「どこまでが前提条件で、どこからが具体的な指示か」を区別しやすくなり、    回答の精度や安定性がアップします。また、人間が見たときも圧倒的にメンテナンスしやすくなります。
     改行を入れない場合（一本の長い文にする）：
    AIが文章の区切りを見失い、指示の一部を読み飛ばしたり、意図しない解釈をしてしまったりする原因になります。

    • プルダウン（ドロップダウンリスト） 実行画面に複数の選択肢（プルダウンメニュー）を表示させたいときに選びます。
      「翻訳する言語（英語／中国語）」や「出力のトーン（ビジネス／カジュアル）」など、入力者に自由入力ではなく決まった項目から選ばせたい場合に最適です。
      入力の手間を減らし、AIの回答を安定させることができます。
      モードプロンプトに貼り付けるコード：プルダウン
      #{title: "プルダウン", type: "select", options:["A", "B", "C", "D", "E"]}

    共通設定

    { } の中には、入力フォームの見た目や入力ルールをカスタマイズするための項目を書き込みます。以下の項目は、テキストボックスやドロップダウンなどすべてのパーツで共通して使用できます。

    • title（タイトル）： 入力欄の上に表示される見出し（ラベル名）になります。
      例：title: "翻訳したい文章" と書くと、入力欄の上に「翻訳したい文章」と太字で表示されます。
    • description（補足説明）： 入力欄のすぐ下などに表示される小さなガイド文（ヒント）になります。
      例：description: "1000文字以内で入力してください" と書くと、フォームを使う人が迷わずに入力できるようになります。
    • optional（入力の必須・任意）： この入力欄を「空欄のまま（任意）で送信してもOKにするか」を設定します。
      例：optional: "true" と書くと、その入力欄は必須ではなくなり、フォームを使う人は何も入力せずにスキップして送信できるようになります。（※指定しない場合は自動的に「入力必須」になります）

    サンプル記入ボタン

    「テキストボックス」や「プルダウン」などの穴埋めパーツを、プロンプト欄にワンクリックで埋め込むことができるボタンです。（※例文が入力されるボタンではありません）
    ボタンを押すと #{title: "テキストボックス", type:'text'} などの穴埋めパーツ用の記号が自動でセットされ、これと連動した入力欄がモードの画面に作られます。
