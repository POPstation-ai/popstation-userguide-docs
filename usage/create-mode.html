モードを作る

対象：全ユーザー

「モード管理」の画面で、AIへの指示や使うAIモデル・参照先・共有範囲を決めて、カスタムモードを作ります。

よく使う指示や設定をカスタムモードとして保存しておくと、条件を入力するだけで同じ使い方ができます。作ったモードは、共有範囲を決めてほかの人にも使ってもらえます。

始める前に

  • カスタムモードは、どのロールの人でも作れます。
  • 組織の設定によっては、作れるモードの共有範囲に上限があります（たとえば「モード作成者のみ」に限られるなど）。詳しくはモードの共有範囲を決めるをご覧ください。
  • 参照先に「カスタムデータ」を使うモードは、カスタムデータを使えるプランでのみ作れます。

手順

  1. 左端のメインサイドバーの「メニュー」を押し、「モード管理」を選びます。「モード管理」の画面が開きます。

  2. 「カスタムモード」のタブを選び、「モード追加」を押します。

  3. 「カスタムモード機能の追加」の画面で、「モードタイトル」「モード説明」「モードプロンプト」を入力します。この3つは必須です。

  4. 実行する人に入力してもらう項目があるときは、「モードプロンプト」の欄の入れたい位置にカーソルを置いてから、欄の下のボタン（「テキストボックス」「プルダウン」「初期値の指定」など）を押します。カーソルの位置に入力項目の書式が入るので、項目名や選択肢を書き換えます。欄に一度もカーソルを置いていないときは、プロンプトの末尾に入ります。

  5. ボタンの下の段の右端にある「フォーマットチェック」を押して、入力項目の書き方を確かめます。「エラーは検出されませんでした。」と表示されれば問題ありません。

  6. ほかの項目を必要に応じて設定します（下の表）。

  7. 「追加」を押します。

保存すると画面が閉じ、「モード管理」の一覧に追加されます。チャット画面の左のサイドバー（「カスタムモード」）にも表示されます。

設定する項目

項目内容
モードタイトル（必須）モードの名前です
モード説明（必須）モードの一覧に表示される説明です。2,000文字まで入力できます
利用ガイドモードの詳しい手順や注意事項です。「モードの実行」の画面に表示されます
モードプロンプト（必須）AIへの指示です。入力項目の書式を入れると、実行するときの「モードの条件入力」に入力欄として表示されます
データ参照先モードで使う参照先です。「カスタムデータ」系を選んだときは、使うフォルダも選びます
参照資料送信のたびに自動で添付するファイルです。20件まで登録できます（モードに参照資料を付ける）
モードカテゴリモードの一覧で、どのカテゴリに表示するかです
モデル実行するときに初めに選ばれるAIモデルです。指定しないときや、指定したAIモデルが使えないとき（提供終了したときなど）は、組織の既定のAIモデル（そのモードで使えないときは、そのモードで使えるAIモデルの先頭）が選ばれます
オリジナルプロンプトの表示モードを実行したときに、利用者の画面にオリジナルのプロンプト（モードプロンプト）を表示するかです
共有範囲・共有先の操作権限モードを使える人と、編集・複製を許可する人です（モードの共有範囲を決める）
利用可能なモデル実行するときに選べるAIモデルです。欄を開くと、AIモデルが区分ごとに1行ずつ並びます。チェックを入れたAIモデルだけが選択肢に表示されます。区分の見出しのチェックで、その区分のAIモデルをまとめて選んだり外したりできます。少なくとも1つ選んでください
公開／非公開（画面の下）「非公開」にすると、チャット画面のモードの一覧に表示されなくなります

項目の詳しい一覧は、モードの作成・編集をご覧ください。入力項目の書き方のコツは、モードプロンプトの書き方をご覧ください。

知っておくと便利なこと

  • 新しく作るモードの共有範囲は、はじめは「組織全体」（同じ組織の全員が使える）になっています。自分だけで使うモードは、「共有範囲」を「モード作成者のみ」に変えてから保存します。組織の設定でモードの作成が制限されている人は、はじめから「モード作成者のみ」になっています（モードの共有範囲を決める）。
  • 「利用可能なモデル」でチェックを入れても、実行する人が使う権限を持たないAIモデルは表示されません。
  • 「新しく追加されたモデルを自動的に許可する」がオンのモードでは、あとから追加されたAIモデルも「利用可能なモデル」で許可された状態になります。
  • 基本モードをもとにして作りたいときは、「基本モード」のタブで、そのモードの「…」から「カスタムモードにコピー」を押します。コピーしたモードは、共有範囲が「モード作成者のみ」になります。
  • 「モードカテゴリ」の選択肢は、管理者とユーザー管理者が「カテゴリ設定」から管理します（モードカテゴリを管理する）。

うまくいかないとき

表示原因と対処
タイトルを記入してください／説明を記入してください／プロンプトを記入してください必須の項目が空です。入力してください
個人モードのみ作成可能です組織の設定で、作れるのは「モード作成者のみ」のモードに限られています。共有範囲を「モード作成者のみ」にしてください
公開モードは作成できません（共有まで作成可能）組織の設定で、「組織全体」のモードは作れません。共有範囲を「指定のユーザーグループ」「指定のユーザー」「モード作成者のみ」のどれかにしてください
N 件の文法エラーが見つかりました。モードプロンプトの入力項目の書き方に誤りがあります。表示された行を直してください
利用可能なモデルを選択してください「利用可能なモデル」が1つも選ばれていません。1つ以上選んでください
フィードバック通知の通知先メールアドレスを1件以上登録してください。ナビゲーションチャットのモードで、「不十分な回答フィードバック時の通知を有効にする」にチェックを入れたのに、通知先がありません。通知先を登録するか、チェックを外してください
参照資料は 20 件まで登録できます（追加すると N 件になります）。選ぶファイルを減らしてください。参照資料は20件までです。選ぶファイルを減らしてください
参照資料が「…」の 1 回の送信の上限を超えています（…）。参照資料を減らすか、利用モデルから「…」を外してください。参照資料だけで、そのAIモデルの1回の送信の上限を超えます。画面は閉じず、保存されていません。参照資料を減らすか、「利用可能なモデル」からそのAIモデルを外してください（モードに参照資料を付ける）

ほかの表示は、エラーメッセージ：モードをご覧ください。
