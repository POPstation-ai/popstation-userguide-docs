モードを実行する

対象：全ユーザー

用途に合わせて指示や設定を用意した「モード」を選び、条件を入力して実行します。実行すると新しいチャットが始まります。

モードは、決まった用途のために、AIへの指示（プロンプト）や使うAIモデル・参照先などをあらかじめ用意したものです。条件を入力して実行すると、新しいチャットが始まります。

モードには2種類あります。

種類内容
カスタムモード組織の中で作ったモード。自分で作ることもできます（モードを作る）
基本モードPOPstationがあらかじめ用意しているモード

手順

  1. 左端のメインサイドバーの「カスタムモード」または「基本モード」を押します。

  2. 左のサイドバーに、カテゴリごとにモードが表示されます。使うモードを押します。

  3. 「モードの実行」の画面が表示されます。「モードの情報」でモードの名前・カテゴリ・説明・デフォルトモデルを確かめます。利用ガイドがあるモードでは、「利用ガイド」も表示されます。

  4. 必要なら、「モデル選択」でAIモデルを、「データ参照先」で参照先を変えます。ファイルを使うときは、「ファイル入力」で添付します。管理者がGoogle ドライブの利用を許可している場合は、「ファイルをアップロード」の下の「Google ドライブから追加」からも添付できます（Google ドライブと連携する）。

    「モデル選択」には、初めにモードの「モデル」に設定されたAIモデルが選ばれています。そのAIモデルが使えないとき（提供終了したときなど）は、組織の既定のAIモデル（そのモードで使えないときは、選べるAIモデルの先頭）が選ばれます。

  5. 「モードの条件入力」の各項目を入力します。必須の項目が空のまま実行しようとすると、「入力してください」または「選択してください」と表示されます。

  6. 「モードを実行する（Ctrl + Enter）」を押します。Ctrl+Enter（MacはCmd+Enter）でも実行できます。

新しいチャットが始まり、AIの回答が表示されます。そのあとは、通常のチャットと同じように続けて質問できます。

知っておくと便利なこと

  • 「プロンプト」を開くと、そのモードがAIに送る指示を確かめられます。
  • 左のサイドバーの「モードを検索」の欄に入れると、モードの名前と説明から探せます（モードを探す）。
  • 左のサイドバーの幅が広いときは、左側にカテゴリの一覧が表示されます。カテゴリを押すと、そのカテゴリの位置に移ります。
  • よく使うモードは、お気に入りに登録しておくと上に表示されます（モードをお気に入りに登録する）。
  • マイページでカスタム指示を登録している場合は、実行ボタンの左に「カスタム指示」のボタンが表示されます（カスタム指示を使う）。
  • 実行したあとで条件やAIモデルを変えたいときは、右のサイドバー（チャット詳細）から再実行できます（条件を変えて再実行する）。

参照資料が付いたモード

参照資料が付いたモードでは、「モデル選択」の下に「このモードには参照資料が N 件付いています（送信のたびに自動で添付されます）。追加で添付できるのは M 件までです。」と表示されます。

  • 参照資料は、送信のたびに自動で添付されます。そのたびに、添付ファイルの利用料金がかかります。
  • 「モデル選択」には、ファイル添付に対応していて、添付できるファイルの数が参照資料の件数以上のAIモデルだけが表示されます。
  • 自分で添付できるファイルの数は、参照資料の件数ぶん少なくなります。参照資料だけで、そのAIモデルで添付できる件数に達しているときは「このモードには参照資料が N 件付いています（送信のたびに自動で添付されます）。この AI モデルでは、ほかのファイルを添付できません。」と表示されます。

詳しくはモードに参照資料を付けるをご覧ください。

一覧に表示されるモード

一覧には、そのモードの共有範囲に自分が含まれているモードだけが表示されます。「非公開」にしたモードや、使えるAIモデルが1つも無いモードは表示されません。

うまくいかないとき

表示原因と対処
機密情報またはNGワードが含まれた入力項目があります入力した内容に、組織で禁止している言葉や機密情報が含まれています。項目ごとに表示された理由を確かめてください。「自動修正する」を押すと、該当する部分を自動で置き換えます。送信を禁止する設定の言葉が含まれていないときは、「修正せずに送信する」でそのまま実行することもできます
プロンプトを読み込めませんでした。画面を再読み込みしてください。モードの指示を読み込めませんでした。画面を再読み込みしてください
サーバーエラーが発生しました実行の処理中にエラーが起きました。もう一度実行してください
このモードでは '…' は利用できません。選んだAIモデルは、このモードでは使えない設定です。別のAIモデルを選んでください
サービス停止中です組織のサービスが停止しているため、実行できません。管理者にお問い合わせください

ほかの表示は、エラーメッセージ：モードとエラーメッセージ：NGワードをご覧ください。
