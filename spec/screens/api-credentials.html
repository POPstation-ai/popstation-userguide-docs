API連携

対象：管理者

業務システムから使うAPIキーを発行・失効する「API連携」画面の項目・操作・出るメッセージです。

手順は業務システムから使えるAPIキーを発行するを、APIの仕様は公開APIの仕様をご覧ください。

この画面を開ける人

管理者が開けます。ユーザー管理者には、メニューが表示されません。

開き方

管理画面の左のメニューで「API連携」を選びます。メニューでは「課金グループ管理」の下にあります。

画面の項目

見出しは「API連携」で、その下に「業務システムから POPstation を呼び出すための APIキーを、利用者ごとに発行・失効します。APIキーからの呼び出しにも、「システム管理」の「アクセス制限」がかかります（管理者に発行したキーも同じです）。IPアドレスを限定しているときは、業務システムのサーバーのIPアドレスを「許可するIP / CIDR」に加えてください。」と表示されます。右上に「発行」があります。見出しの下、一覧の上に「APIの使い方」があります。

APIの使い方

一覧の上の「APIの使い方」を押すと開き、APIを呼び出すときに要る情報が表示されます。初めは閉じています。開くたびに、その時点の組織の設定で読み込み直します（読み込み中は「読み込み中…」）。

節表示される内容
呼び出し先「チャットAPIは次の URL に POST します。」と、組織で使うURL
認証APIキーの付け方（Authorization: Bearer <APIキー>）
curl の例そのまま試せる呼び出しの例。「指定できるモデルID」の先頭のモデルと、「こんにちは」という質問を使います。<APIキー> を発行したキーに置き換えて実行します。右のボタンでコピーできます
応答の例と会話の続け方成功したときに返る形と、同じ会話を続けるときの conversationId の付け方
指定できるモデルID「モデルID」と「表示名」の一覧。「おまかせ」・画像生成・Deep Research・法令 Research は並びません。下に「実際に使えるかは、APIキーの利用者に許可されたモデルによって決まります。許可されていないモデルを指定すると 403 で拒否されます。」と表示されます
上限1回の質問の文字数、1つの会話の合計の文字数、APIキーごとの1分あたりの回数、回答ができるまでの時間（「回答ができるまでの時間: 約2分（125秒）まで（超えると接続が切れ、524 が返ります）」）
主なエラーと対処主なエラーの「状態」「error / code」「原因」「対処」。最後の行は、回答ができるまでの時間の上限を超えたときの 524 です。下に「主なものだけを載せています。このほかのエラーが返ることもあります。回答ができるまでの時間の上限を超えたとき（524）は、本文が JSON ではありません。」と表示されます

「指定できるモデルID」は、組織で使えるAIモデル（海外リージョンモデルの利用の禁止など、組織の設定に合わせたもの）です。APIキーの利用者ごとの許可までは反映しません。詳しい仕様は公開APIの仕様をご覧ください。

発行の画面（「APIキーを発行」）

「発行」を押すと開きます。

項目内容
利用者必須。APIキーを使わせる利用者を選びます。「メールアドレス（ロール）」の形で、メールアドレスの順に並びます。初めは何も選ばれていません（「利用者を選択」）。開いた一覧の「メールアドレスで検索」で探せます
表示名必須。キーの用途が分かる名前で、80文字までです。入力欄には「例: 会計システム連携」と薄く表示されます
「キャンセル」発行せずに閉じます
「発行する」APIキーを発行します。利用者と表示名を入れるまで押せません。処理中は「発行中…」になります

「利用者」の欄の下には「招待済みでまだログインしていない利用者などは、表示されないことがあります。本人がログインすると選べるようになります。」と表示されます。選べる利用者がいないときは、先頭に「発行できる利用者がいません。」が付き、「利用者」は選べません。

「利用者」に並ぶのは、組織のユーザーのうち、削除していない人で、次に当てはまる人です。

環境並ぶ人
インターネット一度ログインした人

失効の確認の画面（「APIキーの失効」）

一覧の「失効」を押すと開きます。

項目内容

注意「※ 失効後は同じキーで API を呼べなくなり、元に戻せません」
「キャンセル」失効せずに閉じます
「このAPIキーを失効」失効します。処理中は「失効中…」になります

操作

操作できる人内容手順のページ
APIキーを発行する管理者「発行」を押し、「利用者」と「表示名」を入れて「発行する」を押します。キーは一度だけ表示されます業務システムから使えるAPIキーを発行する
APIの使い方を見る管理者一覧の上の「APIの使い方」を開きます。呼び出し先のURL・curl の例・指定できるモデルID・上限・主なエラーが表示されます公開APIの仕様
APIキーを失効する管理者一覧の「失効」を押し、確認の画面で「このAPIキーを失効」を押します。失効は取り消せません業務システムから使えるAPIキーを発行する

一覧を見ることと失効することは、ほかの管理者が発行したキーにもできます。

ユーザーを削除すると、そのユーザーのキーは自動で使えなくなります。削除したユーザーを追加し直しても、キーは使えないままです。

環境・契約による違い

プランや機能のオンオフによる違いはありません。「利用者」に並ぶ人は、上の「発行の画面」のとおり環境で違います。APIを呼び出すときの上限は公開APIの仕様をご覧ください。
