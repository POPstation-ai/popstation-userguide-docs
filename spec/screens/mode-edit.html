モードの作成・編集

対象：全ユーザー

カスタムモードを作る・編集する・複製する画面（モーダル）の入力項目・できる人・保存のきまり・出るメッセージです。

手順はモードを作る・モードの共有範囲を決める・モードに参照資料を付けるをご覧ください。モードプロンプトの書き方のコツはモードプロンプトの書き方にまとめています。

この画面を開ける人

開き方開ける人
新しく作る全員。管理者の設定で、作れる共有範囲が限られることがあります
編集・複製管理者・ユーザー管理者・モードの作成者。カスタムデータ管理者と一般ユーザーは、そのモードの「共有先の操作権限」で許可されているとき

開き方

モード管理の「カスタムモード」タブで、次のどれかを押します。

操作画面のタイトル
「モード追加」「カスタムモード機能の追加」
行の「…」から「編集」「カスタムモード機能の修正」
行の「…」から「複製」「カスタムモード機能の複製」（タイトルの末尾に「 のコピー」が付いた状態で開きます）

タイトルの右には「カスタムモード（組織内）」と表示されます。編集のときは、その下に「モード作成者:」と「更新日時:」が表示されます。

画面の項目

上から順に並びます。「必須」の項目は空では保存できません。

項目内容
モードタイトル必須。モードの名前です
モード説明必須。モードの一覧に表示される説明です。2,000文字まで（「0 文字 / 2000文字」のように文字数が表示されます）
利用ガイドモードの詳しい手順や注意を書けます。モードの実行画面に表示されます
モードプロンプト必須。モードを実行したときにAIに送る指示です。欄の下に、入力項目を挿入するボタンと「フォーマットチェック」があります（下の「入力項目の挿入とフォーマットチェック」）
データ参照先モードで参照するものを選びます。「カスタムデータ」「カスタムデータ：ナビゲーションチャット」「Web検索」「URL読込」と、何も参照しない選択肢があります
参照資料カスタムモードだけに表示されます。「資料を追加」で、送信のたびに自動で添付するファイルを登録します（最大20件）。「資料を追加」の右に「N / 20 件」と登録した件数が表示されます。登録したファイルは名前が並び、ごみ箱のボタンで外せます。欄の下に「このモードで送信するたびに、ここに登録したファイルが自動で添付され、AI が毎回参照します。」と表示されます。ラベルの右の ⓘ（マウスを乗せるか、Tab キーで移る）に、登録できる件数・利用者が添付できる数・選べなくなるAIモデル・利用料金の説明があります（モードに参照資料を付ける）
参照データフォルダデータ参照先がカスタムデータのときに、参照するフォルダを選びます（複数選べます）
参照するフォルダを実行のときに選ばせるチェックチェックを入れると「参照データフォルダの選択」のボタンが表示され、モードの実行のときに選ばせるフォルダを決められます。プロンプトに、フォルダを選ぶ入力項目が必要です（下の「参照データフォルダの選択エラー」）
カスタムデータ用RAGプロンプトデータ参照先が「カスタムデータ」のときに、折りたたんで表示されます。検索の結果をAIに渡すときの指示を変えられます。{search_query} と {search_result} が必須です。欄の下の「{search_query}」「{search_result}」のボタンを押すと、カーソルの位置にその語が入ります。空のときは既定の指示を使います
ナビゲーションチャット用RAGプロンプトデータ参照先が「カスタムデータ：ナビゲーションチャット」のときに表示されます。{user_query} {query_expansion} {content_text} が必須です。空のときは既定の指示を使います
フィードバック通知設定データ参照先が「カスタムデータ：ナビゲーションチャット」のときに表示されます。「不十分な回答フィードバック時の通知を有効にする」にチェックを入れ、通知先のメールアドレスを「メールアドレスを検索」で選ぶか、「手動でメールアドレスを追加」で入力します。選んだアドレスは「選択済みメールアドレス」に並びます。通知を有効にして通知先が1件以上あるモードでは、ナビゲーションチャットの最後の質問に「解決のために担当者へ連絡する（担当者へメールを自動送信）」の選択肢が出ます。ウィジェットからだけでなく、チャット画面から使ったときも同じです
参考ファイル名の表示データ参照先が「カスタムデータ」または「カスタムデータ：ナビゲーションチャット」のときに表示されます。「質問の末尾に「参考ファイル(N): ...」を表示する」のチェックで、初めはチェックが入っています。チェックを外すと、このモードで始めたチャットでは、質問の末尾に付く参考ファイル名と参考画像が、画面とエクスポートに表示されなくなります（記録には残ります）
モードカテゴリモードを分類するカテゴリを選びます。初めは「選択してください」です。一度カテゴリを選ぶと、この画面からは未分類に戻せません（モード管理のまとめて操作するバーの「未分類にする」で戻せます）
モデルモードで使うAIモデルです。選ばないときは、組織の既定のAIモデルを使います
オリジナルプロンプトの表示「プロンプトを表示する」「プロンプトを表示しない」。モードを実行したときに、チャットの質問の欄にプロンプトの全文を表示するかどうかです。表示しないときは、モード名と入力した項目だけが表示されます。AIに送る内容は変わりません
共有範囲下の「共有範囲と操作権限」
共有先の操作権限同上
権限プレビュー同上
利用可能なモデル折りたたんで表示され、見出しの右に「26/26件」のように選んでいる数が表示されます。モードを実行するときに選べるAIモデルを選びます。開くと「全選択」「全解除」と、区分（「自動選択」「ファイル入力対応（マルチモーダル）」など）ごとのAIモデルの一覧がその場に並びます。区分の見出しのチェックで、その区分をまとめて選択・解除できます。AIモデルは1行に1つで、ベンダー・名前・精度と速度の星・ⓘ（押すと特徴が表示されます）が並びます。利用者自身が使えないAIモデルは、ここで選んでも表示されません
新しく追加されたモデルを自動的に許可する初めはオンです。オンのモードでは、あとから追加されるAIモデルが「利用可能なモデル」で許可された状態で追加されます。オフにすると、許可されない状態で追加されます。すでにチェックを入れたAIモデルには影響しません
公開「公開」「非公開」のスイッチ。「非公開」のモードは、チャット画面のモードの一覧に表示されません
「追加」／「保存」、「キャンセル」新しく作るとき・複製のときは「追加」、編集のときは「保存」です

入力項目の挿入とフォーマットチェック

モードプロンプトの欄の下のボタンで、モードの実行画面に出す入力項目を挿入できます。入る位置は、モードプロンプトの欄のカーソルの位置です。文字を選んでいるときは、その文字が置き換わります。欄に一度もカーソルを置いていないときは、プロンプトの末尾に入ります。

ボタン実行画面に出る入力項目
テキストボックス1行の入力欄
複数行のテキストボックス複数行の入力欄
プルダウン選択肢から選ぶ欄
プルダウン（初期未選択）初めは何も選ばれていない選択肢の欄
任意記述入力しなくてもよい欄
説明の記述説明付きの入力欄
初期値の指定初めから値が入っている入力欄
条件表示ほかの入力項目の値によって、表示する・しないが変わる欄（モードプロンプトの書き方）

「フォーマットチェック」は、ボタンの段の下の段の右端にあります。押すと、入力項目の書き方にまちがいが無いかを確かめ、結果をその下に表示します。

きまり内容

モード作成の制限管理者が「システム管理」の「モード作成権限」を設定していて、自分のロールが対象のときは、新しく作る・複製するときに選べる共有範囲が限られます。「個人モードのみ作成できる」の場合は「モード作成者のみ」だけです。すでにあるモードを編集するときは、元の共有範囲までは選べます
