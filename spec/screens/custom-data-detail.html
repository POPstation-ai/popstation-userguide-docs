カスタムデータ管理

対象：管理者・ユーザー管理者・カスタムデータ管理者カスタムデータを使えるプランでのみ使えます

カスタムデータのフォルダの中のファイルを登録・削除する「カスタムデータ管理」画面の項目・操作・出るメッセージです。

手順はファイルを登録・削除するをご覧ください。登録できるファイルの形式と大きさはカスタムデータに登録できるファイルにまとめています。

この画面を開ける人

管理者・ユーザー管理者・カスタムデータ管理者が開けます。カスタムデータ管理者が開けるのは、自分が所属するユーザーグループに許可されたフォルダです。

開き方

カスタムデータ登録の一覧で、フォルダ名を押します。

画面の項目

見出しは「カスタムデータ管理」で、その下に「（フォルダ名） のカスタムデータ管理」と表示されます。左の矢印で一覧に戻ります。

項目内容
「カスタムデータ追加」ファイルを登録する画面を開きます
ファイルの一覧下の表の列が並びます
列内容
データ名ファイル名。押すと、ファイルが新しいタブで開きます
サイズファイルの大きさ

追加者登録した人のメールアドレス

ファイルを登録する画面（「カスタムデータの追加」）

項目内容
ファイル形式「PDF、HTML、TXT、DOCX、XLSX、PPTX、CSV、PNG、JPG、JPEG」と表示されます
アップロード可能なファイルサイズ1ファイルの上限が表示されます（下の「環境・契約による違い」）
「ファイル選択アップロード」ファイルを選びます。複数まとめて選べます。選んだファイルの一覧が表示され、行ごとに外せます。選んでいないときは「ファイルが選択されていません」
「Google ドライブから追加」Google ドライブの選択画面を開き、ファイルを選びます。複数まとめて選べます。マイドライブと共有ドライブのファイルを選べます。選んだファイルは、パソコンから選んだファイルと同じ一覧に並びます。下に「Google ドキュメント / スプレッドシート / スライドは Word / Excel / PowerPoint 形式に変換して取り込みます。音声・動画は取り込めません」と表示されます。インターネットの環境で、管理者がGoogle ドライブの利用を許可しているときだけ表示されます
「同名ファイルは上書き更新する」チェックを入れると、同じ名前のファイルを置き換えます
件数「選択 N files」。登録中は「アップロード中 n/N files」
「送信」「キャンセル」「送信」で登録を始めます。ファイルごとに、進み具合・成功・エラーが表示されます

操作

操作できる人内容手順のページ
ファイルを登録する管理者・ユーザー管理者・カスタムデータ管理者「カスタムデータ追加」からファイルを選び、「送信」を押します。すべて成功すると画面が閉じますファイルを登録・削除する
Google ドライブから取り込む管理者・ユーザー管理者・カスタムデータ管理者「カスタムデータ追加」で「Google ドライブから追加」を押してファイルを選び、「送信」を押します。1件ずつ取り込みますファイルを登録・削除する
ファイルを置き換える管理者・ユーザー管理者・カスタムデータ管理者「同名ファイルは上書き更新する」にチェックを入れて登録しますファイルを登録・削除する
ファイルを削除する管理者・ユーザー管理者・カスタムデータ管理者「︙」から「削除」を選び、確認の画面（「カスタムデータ削除」。「カスタムデータ名：…」「カスタムデータを削除しますか？」）で「削除」を押しますファイルを登録・削除する
ファイルの中身を見る管理者・ユーザー管理者・カスタムデータ管理者ファイル名を押します—

登録と削除は、操作履歴に種別「カスタムデータアップロード」「カスタムデータ削除」として記録されます（操作履歴）。Google ドライブから取り込んだファイルも「カスタムデータアップロード」です。

カスタムデータ管理者は、どのユーザーグループにも許可されていないフォルダ（作ったばかりのものなど）を開くと、ファイルの一覧を読み込めず、ファイルの登録もできません（「アクセス権がありません」）。先にカスタムデータ登録の「編集」で、自分が所属するユーザーグループを「許可ユーザーグループ」に設定してください。
