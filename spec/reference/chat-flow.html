チャットのしくみ

対象：全ユーザー

質問を送ってから回答が表示されるまでの流れと、AIに送られるもの、文字数の上限を超えたときに古いやり取りが切り捨てられるしくみです。

チャットで質問を送ると、POPstationはその質問だけでなく、それまでの会話や設定もまとめてAIモデルに送ります。 AIモデルは、前の会話を覚えているのではなく、毎回送られてくる会話の全体を読んで答えています。このページでは、その流れと、送られるもの・切り捨てられるものを説明します。

操作の手順は質問を送る・止めるをご覧ください。

全体の流れ

文章で書くと、次のとおりです。

  1. 送る前の確認（画面）：質問にNGワードや機密情報が含まれていないかを確かめます。含まれていると、送らずに注意が表示されます（NGワードや機密情報が見つかったとき）。
  2. 検索（使うときだけ）：カスタムデータを使うときは、送る前に資料を検索し、その結果を今の質問に差し込みます（カスタムデータ検索（RAG）のしくみ）。Web検索も、多くの場合は送る前に検索して結果を差し込みますが、AIモデルによっては、AIモデル自身がGoogle検索を使って調べます（Web検索・URL読込を使う）。
  3. 送る内容をまとめる：それまでの会話と今の質問、添付ファイルをまとめます。管理者が会話の往復数を制限しているときは、直近の往復だけにします。
  4. 送る前の確認（POPstation）：利用上限に達していないか、そのAIモデルを使えるかを確かめます。「おまかせ」のときは、ここで質問に合うAIモデルを選びます（使えるモデルが決まるしくみ、利用上限と決済失敗時の扱い）。
  5. 最後の調整：カスタム指示を今の質問の前に足し、合計の文字数がAIモデルの上限を超えていれば、古いやり取りから削ります。
  6. AIモデルに送る：添付ファイルは、AIモデルが読める形（画像・PDF・文章）に変えて一緒に送ります。送る前に、会話と添付がAIモデルの上限を超えないかを確かめ、超えるときは送らずに案内を表示します。前の質問の添付の分で超えるときは、古い添付から省いて送ります。ファイルを添付した時点でも、選んでいるAIモデルの1ファイルあたりの上限（PDFのページ数など）を確かめ、超えるファイルは添付しません（ファイル添付の仕様）。
  7. 回答の表示と保存：回答は少しずつ届き、届いた順に画面に表示されます。終わると会話を保存し、料金を記録します。

AIモデルに送られるもの

1回の送信で、AIモデルには次のものがまとめて送られます。

送られるものいつ補足
それまでの会話2回目以降の質問質問と回答の両方です。AIモデルは前の会話を覚えていないので、毎回送ります
今の質問毎回カスタムデータ・Web検索を使うときは、検索の結果を差し込んだ文に置き換わります
モードプロンプトモードのとき会話の最初の質問として、毎回送られます（モードプロンプトの書き方）
カスタム指示マイページで設定し、入力欄の「カスタム指示」がオンのとき毎回、今の質問の前に足されます（マイページ（ユーザー名・カスタム指示））
添付ファイル同じチャットで添付したファイルがあるとき前の質問で添付したファイルも、そのやり取りが会話に残っている間は、毎回もう一度送られます。 AIモデルの上限（画像の枚数など）を超える分は、古い質問の添付から省きます

添付ファイルは、送るたびに料金がかかります

前に添付したファイルも、会話の一部として毎回AIモデルに送られるので、質問を送るたびに、その添付ファイルの料金がかかります。 たとえば、10ページのPDFを添付して質問を3回送ると、PDF 30ページ分の料金になります。添付したファイルについて聞き終わったら、新しいチャットを始めると料金を抑えられます（ファイル添付の仕様）。

古いやり取りが送られなくなるしくみ

会話が長くなると、古いやり取りはAIモデルに送られなくなります。画面のチャット履歴からは消えません。 送られなくなるだけです。しくみは2つあります。

1. 往復数の制限（管理者の設定）

管理者がシステム管理の「チャット体験設定」で「会話履歴を往復数で制限」をオンにしていると、AIモデルに送るのは直近の決めた往復数（5〜20、既定は5）までになります。制限がかかるときは、入力欄の上に「管理者設定により、直近 N 往復の会話のみを参照しています…」と表示されます（チャットの表示と会話履歴の長さを設定する）。

2. 文字数の上限（AIモデルごと）

送る内容の合計の文字数が、AIモデルごとに決まった上限を超えると、会話の古い方から、超えた分の文字を削ってから送ります。

項目内容
数える対象会話のすべての文字（モードプロンプト・それまでの質問と回答・カスタム指示・今の質問。カスタムデータやWeb検索の結果を差し込んだときは、その文字も含む）
上限AIモデルごとに決まっています。例：多くのAIモデルは500,000文字、GPT-5.5は136,000文字、Claude Sonnet 5.5は100,000文字、画像生成モデルは15,000文字。全モデルの値はAIモデル一覧の「上限文字数」にあります
削り方いちばん古いやり取りから順に、まるごと削ります。最後の1つは、超えた分だけ先頭の文字を削ります
表示削ったことは画面に表示されません。 回答が前の話を踏まえていないときは、これが原因のことがあります
添付ファイル添付ファイルの中身は、この文字数には数えません。そのかわり、送る前に、会話と添付ファイルを合わせた量を見積もります。AIモデルが一度に扱える量を超えると見込まれるときは、AIモデルに送らずに、AIの回答欄に「送信内容が、選択中の AI モデルで一度に扱える上限を超えているため、送信できませんでした。…」と表示します（ファイル添付の仕様、エラーメッセージ：チャット送信）

例：上限が100,000文字のAIモデルで、会話の合計が120,000文字になったとき、古い方から20,000文字分のやり取りが送られなくなります。モードの会話がとても長くなると、最初の質問として送っているモードプロンプトから削られることもあります。

長い会話は、区切りのよいところで新しいチャットに

話題が変わったときや、会話がとても長くなったときは、新しいチャットを始めます。前の会話の要点が必要なら、AIに要約させてから、その要約を新しいチャットに貼り付けます。料金も抑えられます。

回答の表示

項目内容
少しずつ表示される回答はできた順に少しずつ届き、届いた順に表示されます
止める回答の途中で停止ボタンを押すと止まります。扱いは質問を送る・止めるをご覧ください
長さの上限1回の回答の長さにも上限があり、とても長い回答は途中で終わることがあります。そのときは「続けて」と送ります。上限は、AIが文章を数える単位（トークン）で、Claude Opus 5.5・Claude Opus 5は32,000、Claude Sonnet 5.5・Claude Sonnet 5・Claude Haiku 4.5は64,000です。Geminiの系統とGPTの系統のAIモデルは、POPstationでは上限を決めておらず、提供元の上限までです
保存会話はチャット履歴に保存されます。管理者は、AIチャットログで組織の利用状況を確かめられます（AIチャットログを見る・ダウンロードする）

AIモデルが「覚えている」こと・「覚えていない」こと

覚えていること覚えていないこと
同じチャットの中で、AIモデルに送られている範囲の会話別のチャットの会話（チャットごとに別です）
マイページのカスタム指示（適用しているとき）切り捨てられた古いやり取り
モードのモードプロンプト（モードのとき）前の質問で検索したカスタムデータの断片（質問のたびに検索し直します）

入力欄の上に「入力した内容はAIモデルの学習に使われません。…」と表示されているとおり、入力した内容がAIモデルの学習に使われることはありません（生成AIのしくみ）。
