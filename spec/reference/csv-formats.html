CSVの形式

対象：管理者・ユーザー管理者

管理画面でダウンロード・アップロードするCSVファイルの形と列の一覧です。

管理画面でやり取りするファイルは、すべてCSV形式です。Excelで開けるように、文字コードはBOM付きのUTF-8です。

ユーザー情報CSV（更新用）

「ユーザー管理」の「ユーザー情報CSVダウンロード (更新用)」でダウンロードし、「ユーザー情報CSVで一括更新」でアップロードします。手順はCSVでまとめて登録・更新・削除するをご覧ください。

ファイルに載っていないユーザーは削除されます

アップロードすると、ファイルに載っていないユーザー（あなたが操作できるユーザーだけ）は削除されます。実行の前に、削除されるユーザーの一覧が確認のために表示されます。

ファイルの形

項目内容
ファイル名「ユーザー一覧_年月日_時分秒.csv」
1行目列の見出し
2行目列の説明
3行目入力の例
4行目区切りの行（「---以下の5行目からインポートが有効になります---」。読み取り専用の列は「---以下の行を変更しても更新されません---」）
5行目からユーザーのデータ。取り込まれるのは5行目からです
文字コード（アップロード）UTF-8（BOMはあってもなくてもかまいません）

列

列の見出し入力する値補足
No.—読み取り専用です。変えても反映されません
登録状態—読み取り専用です（「登録済み」または「未登録」）。
メールアドレスユーザーのメールアドレス必須です
権限user（一般ユーザー）・user-admin（ユーザー管理者）・custom-data-admin（カスタムデータ管理者）・admin（管理者）のどれか必須です。付けられるロールは操作する人によって違います（ロールと権限の一覧）
ユーザーグループ名所属させるユーザーグループの名前。複数はカンマで区切ります空欄なら「全体」に所属します。存在しない名前を書くと、そのユーザーグループが自動で作られます。名前にカンマや引用符を含む場合は、名前全体が「"」で囲まれて出力されます。囲まれたままアップロードしてください
メール通知0（送らない）・1（送る）必須です。新規登録と権限の変更のときに通知します
（AIモデルの表示名）制限0（制限しない）・1（制限する）AIモデルごとに1列あります。空欄は0です。先頭は「おまかせ制限」です
（Geminiの系統の表示名）動画・音声制限0（制限しない）・1（制限する）動画・音声を扱えるGeminiの系統のモデルだけ、そのモデルの「制限」の列のすぐ右にあります。空欄は0です。モデル自体を制限している場合は無効です
制限カスタムデータフォルダ使わせないカスタムデータのフォルダの名前。複数はカンマで区切ります空欄なら制限しません
新メールアドレス変更後のメールアドレス書いた場合は、確認メールが送られます。空欄なら変更しません
個別MFA—読み取り専用です（「有効」または「無効」）。組織全体の多要素認証の設定は含みません

AIモデルの列は組織によって変わります

AIモデルの列は、その組織で表示されるAIモデルだけが並びます。列の見出しはAIモデルの表示名から作られ、アップロードのときに1文字も違わないかが確かめられます。AIモデルの追加・終了・名前の変更があると、列の見出しが変わります。前にダウンロードしたファイルをアップロードすると、「フォーマットが古いため失敗しました。最新の CSV テンプレートをダウンロードしてください（N 列目: 期待「…」/ 実際「…」）」と表示されます。アップロードの直前に、あらためてダウンロードしてください。

取り込んだあと

項目内容
エラーレポート取り込めなかった行は、画面の「エラーレポート」に「行番号」「メールアドレス」「エラー内容」で表示されます。行番号はファイルの行の番号で、最初のデータの行が5です。あなた自身の行と、操作する権限の無いユーザーの行も、ここに表示されます
パスワード設定URL一覧（インターネット）新しいユーザーがいると、「パスワード設定URL一覧_年月日_時分秒.csv」が自動でダウンロードされます。列は「メールアドレス」「パスワード設定URL」「メール送信状態」（「送信済」または「未送信」）です

エラーの内容と対処は、エラーメッセージ：CSVをご覧ください。

絞り込み結果をCSV出力

項目内容
ファイル名「AIチャットログ_年月日_時分秒.csv」
期間最大366日
件数最大10,000件。超えるときは「月別ダウンロードを申請」を使います
値の先頭の記号先頭が「=」「+」「-」「@」の値には、表計算ソフトで式として扱われないように、先頭に「'」が付きます

列は次のとおりです。

列内容
日時送信した日時（年/月/日 時:分:秒）
ユーザーメールアドレス
モデル使ったAIモデル
送信本文・返信本文質問と回答の本文
送信文字数・返信文字数質問と回答の文字数です（トークン数ではありません）
添付ファイル添付したファイルの名前。複数は「 / 」で区切ります
参照カスタムデータ参照したカスタムデータのフォルダの名前。複数は「 / 」で区切ります
セッションID・ターン番号チャットを見分ける番号と、何往復目か
添付画像枚数・添付PDFページ数・添付音声秒数・添付動画秒数・添付テキスト文字数添付の種類ごとの量
添付件数添付したファイルの数
添付課金数量未確定件数量がまだ確定していない添付の数

月別ダウンロード

「月別ダウンロードを申請」で月を選んで申請すると、準備ができたときに「POPstation ログダウンロードの準備ができました」というメールが届きます。ファイルは「ダウンロード管理」で受け取ります（ダウンロード管理）。

項目内容
受け取れる人申請した本人だけです
受け取れる回数1回だけです。受け取るとファイルは削除されます

列の見出しは英語で、次のとおりです。

列内容
Created At送信した日時
Email・User Name・User IDユーザーのメールアドレス・名前・ID
Request Text・Response Text質問と回答の本文
Usage Prompt・Usage Completion質問と回答の文字数です（トークン数ではありません）
Topicチャットの名前
Session ID・Chat Turnsチャットを見分ける番号と、何往復目か
Mode使ったモードの名前
Model使ったAIモデル
Multi Turn Noナビゲーションチャットのやり取りの段階です。候補を示す段階の行が 1、候補を選んだあとの回答の行が 2 です。ナビゲーションチャット以外は空欄です
Multi Feedbackナビゲーションチャットで選んだもの（下の表）。ナビゲーションチャット以外は空欄です
User Question・Selected Optionナビゲーションチャットの質問と、選んだ候補
Attachment Image Count・Attachment PDF Pages・Attachment Audio Seconds・Attachment Video Seconds・Attachment Text Chars・Attachment File Count・Attachment Unconfirmed Count添付の量（上の表の「添付画像枚数」〜「添付課金数量未確定件数」と同じ内容）

「Multi Feedback」の値は次のとおりです（選択肢の文言はナビゲーションチャットを使う）。INCORRECT_ANSWERだけは、候補を示す段階の行（Multi Turn No が 1）に入ります。ほかの値は、回答の行（Multi Turn No が 2）に入ります。

値意味
NO_FEEDBACK最後の回答のあと、まだ選択肢を選んでいない
SATISFIED「解決しました（チャットを終了）」か「はい（解決しました）」を選んだ
UNRESOLVED_NO_CONTACT「解決しませんでした（チャットを終了）」か「いいえ（まだ不明な点があります）」を選んだ
INSUFFICIENT_ANSWER「解決のために担当者へ連絡する（担当者へメールを自動送信）」を選んだ
INCORRECT_ANSWER示された候補に当てはまるものが無く、「いずれでもない」「どちらでもない」「上記の回答が合っていない」を選んだ

操作履歴のCSV

「操作履歴」の「CSVダウンロード」でダウンロードします。「適用」した絞り込みの条件で出力されます。

項目内容
ファイル名「操作履歴_年月日_時分秒.csv」
期間最大366日
列「操作日時」「操作種別」「操作ユーザー」「対象」「詳細」「IPアドレス」
操作種別画面の「操作」の列の値が入ります（例：「ユーザー追加」「課金グループを作成」「上限通知先を追加」「チャット共有URLを発行」「共有されたチャットを閲覧」「MFA認証成功」）。画面の「種別」の値は出力されません
操作ユーザー操作した人のメールアドレス。提供を終了したAIモデルのために既定のAIモデルが自動で切り替わった記録は「システム自動」です

絞り込みに使える種別は、「ログイン」「ログアウト」「システム設定変更」「ユーザー追加・更新」「ユーザー削除」「カスタムデータアップロード」「カスタムデータ削除」「MFA」「お知らせ」「アカウント操作」「チャット共有」「チャット添付の取り込み」「API連携」です。種別ごとの記録の内容は操作履歴をご覧ください。
